# Epicmotchi · Sensor

Página para el celular que muestra el sensor de temperatura y humedad de la placa de tinta (Waveshare ESP32-S3-ePaper-1.54G) de Yo Épico Outdoor Hospitality.

Lee las lecturas del puente de Epicmotchi (Apps Script, `?vista=sensor`) y el pronóstico de afuera de Open-Meteo. La dirección del puente y su clave se guardan solo en el teléfono; este repositorio no contiene ninguna.
